# 📚 Personalized Learning Website — 1-on-1 Trial Booking Platform

A modern, responsive, and interactive educational website built using **React.js** and **Tailwind CSS**. This project allows users to explore personalized learning programs, understand the curriculum, view pricing, read testimonials, and **book a free 1-on-1 trial class** — all from a sleek and professional single-page application.



## 🚀 Features

### ✅ Hero Section
- Bold, attention-grabbing headline
- Clear subheading explaining the value of the course
- “Book a Free Trial” CTA with modal form
- Engaging hero image or illustration

### ✅ What You’ll Learn (Curriculum Snapshot)
- Grid or timeline-style layout
- Lists of 5–6 core modules/topics with icons and short descriptions

### ✅ Why Choose Us (USPs)
- Highlights 4–6 Unique Selling Points like:
  - 1-on-1 Live Sessions
  - 24/7 AI Doubt Support
  - Personalized Learning Path
  - Weekly Progress Reports
  - Access to Session Recordings
  - Industry-relevant Tools
- Each feature shown with an icon, title, and short description

### ✅ Student Experience (How It Works)
- Illustrated as a timeline or stepper showing steps like:
  1. Book a Free Trial
  2. Choose Your Mentor
  3. Attend Live 1-on-1 Classes
  4. Get Doubt Support + Recordings
  5. Track Progress Every Week

### ✅ Testimonials / Success Stories
- Displays real/dummy student reviews
- Includes name, country flag, and feedback quote

### ✅ Pricing Plans
- 3 tier options: 3 months, 6 months, 12 months
- Price per hour
- Comparison table of included benefits

### ✅ Bottom Call-to-Actions
- Persistent or section-based CTA options like:
  - Talk to a Counsellor
  - Book a Free Trial
  - Chat with AI Mentor
