# Mohd Aqab Sami Portfolio

A personal portfolio website built with React, TypeScript, Vite, and Tailwind CSS.

## Highlights

- Intro section with profile photo and resume download
- Certifications, skills, and project showcases
- Admin panel for updating global portfolio content
- Firebase-backed content sync
- Deployment support for both GitHub Pages and Firebase Hosting

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

GitHub Pages:

```bash
npm run deploy
```

Firebase Hosting:

```bash
npm run firebase:deploy
```
